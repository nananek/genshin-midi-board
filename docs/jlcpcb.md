# JLCPCB 向け製造制約

| 項目 | 値 |
| --- | --- |
| 外形 | 57.6 × 31.4 mm |
| 厚さ | 1.6 mm |
| 層数 | 4 |
| 銅 | 外層 1 oz、内層 0.5 oz |

## 2. ビアと配線

### 使うビア

- 径 0.5 mm、ドリル 0.3 mm のスルービアのみ
- テントのまま。プラグ、キャップ、フィルはしない
- 盲埋め込みビアは使わない

### 使わないビア

- 0.15 mm ドリル
- via-in-pad
- レーザービア
- 樹脂充填ビア

### 配線

- 最小配線幅 / 間隔: 0.127 / 0.127 mm
- 通常の信号: 0.15 mm
- USB D+/D-: 0.2 mm
- QFN-56 の逃げ: 0.127 mm
- +5V / VBUS: 0.8 mm 以上
- USB-A の VBUS: 1.0 mm を基本
- 基板端から銅まで 0.3 mm 以上

## 3. PR #22 の教訓

`serial-km-emulator` の PR #22 では、USB データ線の逃げに 0.15 mm ドリルのビアを 10 本使ったため、JLCPCB の次のオプションが自動で付きました。

| 項目 | 金額 |
| --- | ---: |
| 基板本体（Special Offer） | ¥629 |
| Min via hole size/diameter 0.15 mm | ¥5,276 |
| Via Covering: Plugged | ¥2,606 |
| 4-Wire Kelvin Test | ¥2,621 |
| 合計 | ¥11,132 |

0.15 mm ドリルを 1 本でも入れると、同じオプションが戻る可能性があります。今回の設計では、ドリルファイルに 0.15 mm が 1 本もないことを発注前に確認します。

確認コマンドの例:

```sh
grep -E "T[0-9]+C0\.15" gerbers/*.drl
# 何も出ないこと
```

すべてのビアが 0.3 mm ドリルであることを確認します。

```sh
grep -E "T[0-9]+C0\.3" gerbers/*PTH.drl
```

PTH にはコネクタやスイッチの 0.9 mm、1.0 mm、2.3 mm などのドリルも入ります。0.15 mm が混ざっていなければ問題ありません。

## 4. Type-C の逃げ

HRO TYPE-C-31-M-12 の A7/B7 は、パッド内ビアを使わずに逃がします。

1. A7/B7 のパッドから基板内側へ 0.15 mm の配線を出す
2. パッドの外側に 0.5/0.3 mm のビアを置く
3. ビアから In1 の GND を基準にした配線で RP2040 または CH345T へ向かう
4. パッドとビアの間は 0.15 mm 以上空ける

PR #22 と同じ考え方です。JLCPCB の DFM プレビューで via-in-pad の指摘が出ないことを確認します。

## 5. QFN-56 の逃げ

RP2040 の QFN-56 は 0.4 mm ピッチです。パッド間に配線を通さず、すべて外側へ逃がします。

- パッドから 0.127 mm の配線を外側へ出す
- パッド列の外に 0.5/0.3 mm のビアを置く
- サーマルパッド内にビアを置かない
- サーマルパッドは F.Cu の GND ベタと接続し、パッド外のビアで In1 へ落とす

0.127 mm は JLCPCB の 4 層基板の最小配線幅です。0.15 mm で余裕が取れる箇所は 0.15 mm を使います。

## 6. 部品と実装

### SMT

| Ref | 部品 | パッケージ | LCSC |
| --- | --- | --- | --- |
| U1 | RP2040 | QFN-56 | C2040 |
| U2 | W25Q128JVSIQ | SOIC-8 | C97521 |
| U3 | CH345T | SSOP-20 | C5246448 |
| U4 | AP2112K-3.3TRG1 | SOT-23-5 | C51118 |
| U5 | TPS2553DBVR | SOT-23-6 | C55266 |
| U6-U8 | USBLC6-2SC6 | SOT-23-6 | C7519 |
| J1/J3 | TYPE-C-31-M-12 | USB-C 16P | C165948 |

### 手はんだ（THT）

- J2: USB-A 5075AR-04-WH（Akizuki 100160）
- SW1-SW4: NKK 115643（Akizuki 115643）
- SW6: DTS-63-N-V-BLK（Akizuki 103647）
- C27: 100 uF 電解コンデンサ

USB-C の J1/J3 は SMT パッドと THT のシェル固定タブを持ちます。JLCPCB の SMT 実装リストに C165948 が含まれているため、SMT で発注できます。シェルタブの半田が不安なら、手はんだを追加します。

## 7. CPL の回転

JLCPCB の部品ライブラリと KiCad のフットプリントでは、回転の基準がずれることがあります。次の部品は実装プレビューで向きを確認します。

- J1/J3: USB-C の口が基板外側を向いているか
- U3: CH345T のピン 1 の向き
- U5: TPS2553 のピン 1 の向き
- U1: RP2040 のピン 1 の向き
- U6-U8: USBLC6 のピン 1 の向き

USB-C は J1 と J3 で回転が同じです。CPL の X/Y と回転を、KiCad の配置と突き合わせます。Type-C の CPL はコネクタ軸方向に補正が必要になる場合があります。`serial-km-emulator` の `scripts/make_jlc_files.py` の補正値を参考にします。

## 8. 発注前チェックリスト

1. 4 層、1.6 mm、57.6 × 31.4 mm、四隅 2 mm パンチカットになっている
2. ドリルファイルに 0.15 mm がない
3. すべてのビアが 0.5/0.3 mm である
4. via-in-pad がない
5. plugged / capped / filled になっていない
6. DRC が 0 violations / 0 unconnected
7. ERC が 0 violations
8. QSPI の等長と長さを確認した
9. USB D+/D- の長さ差が 2 mm 以内
10. Type-C の CC に 5.1 kΩ がある
11. USB-A の VBUS に TPS2553 と SW4 が入っている
12. BOM の LCSC 型番がすべて有効
13. CPL の回転と位置を実装プレビューで確認した
14. 1:1 印刷でコネクタとスイッチの位置を確認した
15. 紙ケースの開口位置を現物合わせした

## 9. 費用の考え方

4 層基板は 2 層より高いですが、6 層より安く、0.15 mm ビアや via-in-pad のオプションを避けられます。部品点数は RP2040、flash、CH345T、LDO、TPS2553、ESD ×3、コネクタ ×3、スイッチ ×6、水晶 ×2、パッシブ約 40 点です。

拡張部品（RP2040、CH345T、TPS2553、USBLC6、USB-C、W25Q128）は 1 種類あたりの実装手数料がかかります。5 枚程度の試作では、部品代より手数料と送料の比率が大きくなります。まず 5 枚で組み、動作を確認してから 10〜20 枚に増やす方針が現実的です。

## 10. リスク

- CH345T の在庫が少ない。現行基板の BOM では在庫 120 個（5 枚なら足りる）。発注直前に在庫を確認する。
- RP2040 の在庫と価格。RP2350 より安いが、入手性は定期的に確認する。
- USB-A の Neltron コネクタは JLCPCB に在庫がない。手はんだ用に別途購入する。
- 4 層の 0.3 mm ドリルが JLCPCB の標準範囲か、発注画面で確認する。
- Type-C ケーブルの樹脂部が 29 mm ピッチでも干渉する可能性。実物で確認する。
