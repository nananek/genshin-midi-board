# Project-local libraries

Only what the official KiCad libraries cannot provide is kept here.

## rp2040_frisk.kicad_sym

Generated by `../scripts/gen_sch.py`. It contains

* copies of the official KiCad 10 symbols used by the schematic
  (`MCU_RaspberryPi:RP2040`, `Memory_Flash:W25Q128JVS`,
  `Regulator_Linear:AP2112K-3.3`, `Power_Protection:USBLC6-2SC6`,
  `Connector:USB_C_Receptacle_USB2.0_16P`, `Connector:TestPoint`,
  `Device:Crystal_GND24`, `Device:R`, `Device:C`, `Device:C_Polarized`,
  `Device:D_Schottky`, `Device:LED`, `Switch:SW_SPDT`, `power:+5V`,
  `power:+3V3`, `power:GND`, `power:PWR_FLAG`). Symbols that use `extends`
  in the official libraries are flattened, so the file is self-contained.
* project symbols without an official equivalent: `CH345T`,
  `TPS2553DBVR`, `USB_A_6P` (Neltron receptacle with two shell tabs),
  `SW_TACT_4P` (4-pin DTS-63 tact switch) and the `+1V1`, `VBUS_PC`,
  `VBUS_IPAD`, `VBUS_USB_A` power ports.

Do not edit the file by hand; change the generator and re-run it.
